> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> Status: not started. Execute on branch `release-0.9.0` from `main` after v0.8.0 (plan `2026-09-15-release-0.8.0-tags-own-types.md`) is merged and tagged.
> Implements the "Settings the web has" part of phase 5 in `docs/superpowers/specs/2026-09-14-logb-android-next-design.md`.
> QR sign-in (phase 6) is not web parity and gets its own plan.
> Deviation from the spec, found in logb's code while planning (2026-09-15): `DELETE /api/auth/tokens/{id}` needs an
> interactive session (`SessionUser`) exactly like `POST /api/auth/tokens`; the spec assumed revoking worked with a token.
> Both therefore ask for the password once and go through a short cookie session.
> With this release the app does everything a signed-in, non-admin person does in the web client; Settings › People and
> Settings › Database stay web-only (spec 1, decision 3), and browser push stays web-only (spec 2, decision 7).

**Goal:** Settings gains the web's Data page (export everything, import a zip), API access page (list, create, revoke tokens) and the server-side digest settings (webhook, format, test), all with the web's wording.

**Architecture:** A `PasswordSession` helper in `core/auth` runs one block of calls on a short-lived cookie session (login, block, logout) for the two token calls that refuse a token. Each page is a stateless `…Content` composable driven by a small `@HiltViewModel` that calls the signed-in `LogbApi`; files move through the Storage Access Framework (`CreateDocument` / `OpenDocument`) as streams, never loaded whole. Every page needs the network and says so when offline.

**Tech Stack:** As release 0.8.0. No new dependencies.

## Global Constraints

- Token names are trimmed, `1..64` characters. A created token's plaintext is shown once on screen with a Copy button and kept only in the view model's memory; it is never written to disk, logs or DataStore.
- The phone's own token (`ServerRecord.tokenId`) is listed as "this phone" and cannot be revoked from the list (signing out does that).
- `POST /api/auth/tokens` and `DELETE /api/auth/tokens/{id}` go through `PasswordSession`: `POST /api/auth/login` with the signed-in username and the password the user types, the call, then `POST /api/auth/logout` (best effort). The password is not stored.
- Export: `GET /api/export` streamed into the document the user picks (suggested name `logb-export-<yyyy-MM-dd>.zip`, MIME `application/zip`).
- Import: the picked document streamed as the raw body of `POST /api/import` with `Content-Type: application/zip`; the server's default limit is 1024 MB (`LOGB_MAX_IMPORT_MB`), 413 means too large. After a successful import the mirror requests a bootstrap and a sync runs. Before uploading, the page warns that import adds everything and a second import duplicates objects and entries.
- Server digest: `GET/PUT /api/me/notifications` (`url` — http or https with a host, blank means none; `format` — `text` or `json`), `POST /api/me/notifications/test`; the instance hour (`hour`) is shown read-only. Browser push settings are not shown.
- Offline, each page shows "needs a connection" instead of failing.
- Wording is the web's (`logb/frontend/src/i18n/en.ts`, `de.ts`), in `values/strings.xml` and `values-de/strings.xml`. Lint `warningsAsErrors`; fix, don't suppress.
- Default version `0.9.0` / `900`.
- Commands from `/home/ben/repo/logb_mobile`; Gradle in the foreground with Bash timeout 600000; device tests only on an emulator via `adb -s emulator-5554`; `./gradlew --stop` afterwards.

- [ ] **Step 3: `PasswordSession.kt`**

```kotlin
package dev.logb.android.core.auth

import dev.logb.android.core.network.LogbApi
import dev.logb.android.core.network.dto.Credentials
import javax.inject.Inject

/**
 * One block of calls on a short cookie session. logb creates and revokes API tokens only for an
 * interactive login (`SessionUser`): a token that could mint tokens would be a leak that repairs
 * itself. So the password is typed, used for this login, and forgotten; the phone's own token is
 * never sent on these calls.
 */
class PasswordSession @Inject constructor(private val sessions: SessionRepository, private val apiFactory: ApiFactory) {
    suspend fun <T> run(password: String, block: suspend (LogbApi) -> T): Result<T> = runCatching {
        val signedIn = sessions.session.value as? Session.SignedIn ?: error("signed out")
        val api = apiFactory.create(signedIn.serverUrl, { null }, InMemoryCookieJar())
        api.login(Credentials(signedIn.user.username, password))
        try {
            block(api)
        } finally {
            runCatching { api.logout() }
        }
    }
}
```

```kotlin
package dev.logb.android.feature.settings.tokens

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import dagger.hilt.android.lifecycle.HiltViewModel
import dev.logb.android.core.auth.ActiveAccount
import dev.logb.android.core.auth.PasswordSession
import dev.logb.android.core.auth.ServerStore
import dev.logb.android.core.network.dto.ApiToken
import dev.logb.android.core.network.dto.NewToken
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch
import javax.inject.Inject

data class TokenRow(val token: ApiToken, val isThisPhone: Boolean)

object TokenRows {
    fun of(tokens: List<ApiToken>, phoneTokenId: Long?): List<TokenRow> = tokens.map { TokenRow(it, it.id == phoneTokenId) }

    fun validName(raw: String): String? = raw.trim().takeIf { it.isNotEmpty() && it.codePointCount(0, it.length) <= 64 }
}

sealed interface PasswordAction {
    data class Create(val name: String) : PasswordAction
    data class Revoke(val token: ApiToken) : PasswordAction
}

data class TokensUiState(
    val rows: List<TokenRow> = emptyList(),
    val loaded: Boolean = false,
    val offline: Boolean = false,
    val name: String = "",
    /** The plaintext of the token just created: memory only, gone when the screen is. */
    val fresh: String? = null,
    val asking: PasswordAction? = null,
    val busy: Boolean = false,
    val error: String? = null,
)

@HiltViewModel
class TokensViewModel @Inject constructor(
    private val accounts: ActiveAccount,
    private val serverStore: ServerStore,
    private val passwordSession: PasswordSession,
) : ViewModel() {
    private val _state = MutableStateFlow(TokensUiState())
    val state: StateFlow<TokensUiState> = _state.asStateFlow()

    init { load() }

    fun load() = viewModelScope.launch {
        runCatching { TokenRows.of(accounts.api.listTokens(), serverStore.read()?.tokenId) }
            .onSuccess { rows -> _state.update { it.copy(rows = rows, loaded = true, offline = false, error = null) } }
            .onFailure { e -> _state.update { it.copy(loaded = true, offline = e is java.io.IOException, error = e.message.takeUnless { e is java.io.IOException }) } }
    }

    fun onName(v: String) = _state.update { it.copy(name = v) }

    fun askCreate() { TokenRows.validName(_state.value.name)?.let { n -> _state.update { it.copy(asking = PasswordAction.Create(n), error = null) } } }

    fun askRevoke(token: ApiToken) = _state.update { it.copy(asking = PasswordAction.Revoke(token), error = null) }

    fun dismiss() = _state.update { it.copy(asking = null) }

    fun confirm(password: String) = viewModelScope.launch {
        val action = _state.value.asking ?: return@launch
        _state.update { it.copy(busy = true, error = null) }
        val result = passwordSession.run(password) { api ->
            when (action) {
                is PasswordAction.Create -> api.createToken(NewToken(action.name)).token
                is PasswordAction.Revoke -> { api.revokeToken(action.token.id); null }
            }
        }
        result.onSuccess { plaintext ->
            _state.update { it.copy(busy = false, asking = null, fresh = plaintext ?: it.fresh, name = if (plaintext != null) "" else it.name) }
            load()
        }.onFailure { e -> _state.update { it.copy(busy = false, error = e.message) } }
    }
}
```

```kotlin
import okhttp3.MediaType

import okio.source
import java.io.InputStream
import java.io.OutputStream
import java.time.LocalDate

/** Streams, both ways: an export or an import can be hundreds of megabytes; nothing is held whole in memory. */
object DataTransfer {
    private val ZIP: MediaType = "application/zip".toMediaType()

    suspend fun export(api: LogbApi, out: OutputStream): Long = api.exportAll().use { body -> body.byteStream().use { it.copyTo(out) } }

    fun zipBody(open: () -> InputStream, length: Long): RequestBody = object : RequestBody() {
        override fun contentType(): MediaType = ZIP
        override fun contentLength(): Long = length
        override fun writeTo(sink: BufferedSink) { open().source().use { sink.writeAll(it) } }
    }
```

```kotlin
    val exported: Boolean = false,
    val imported: ImportCounts? = null,
    val pendingImport: Uri? = null,
    val error: DataError? = null,

enum class Busy { Exporting, Importing }
enum class DataError { Offline, TooLarge, Other }

@HiltViewModel
class DataViewModel @Inject constructor(
    @ApplicationContext private val context: Context,
    private val accounts: ActiveAccount,
    private val syncManager: SyncManager,
) : ViewModel() {
    private val _state = MutableStateFlow(DataUiState())
    val state: StateFlow<DataUiState> = _state.asStateFlow()
    var lastErrorMessage: String? = null
        private set

    fun export(to: Uri) = viewModelScope.launch {
        _state.update { DataUiState(busy = Busy.Exporting) }
        val result = withContext(Dispatchers.IO) {
            runCatching { context.contentResolver.openOutputStream(to)!!.use { out -> DataTransfer.export(accounts.api, out) } }
        }
        _state.update { s -> result.fold({ s.copy(busy = null, exported = true) }, { e -> s.copy(busy = null, error = classify(e)) }) }
    }

    /** Asks first: import adds everything, and a second import duplicates. */
    fun askImport(from: Uri) = _state.update { DataUiState(pendingImport = from) }

    fun cancelImport() = _state.update { it.copy(pendingImport = null) }

    fun confirmImport() = viewModelScope.launch {
        val uri = _state.value.pendingImport ?: return@launch
        _state.update { DataUiState(busy = Busy.Importing) }
        val result = withContext(Dispatchers.IO) {
            runCatching {
                val length = context.contentResolver.query(uri, arrayOf(OpenableColumns.SIZE), null, null, null)?.use { c -> if (c.moveToFirst()) c.getLong(0) else -1L } ?: -1L
                accounts.api.importZip(DataTransfer.zipBody({ context.contentResolver.openInputStream(uri)!! }, length))
            }
        }
        result.onSuccess { counts ->
            accounts.db.syncStateDao().requestBootstrap()
            _state.update { it.copy(busy = null, imported = counts) }
            syncManager.syncNow()
        }.onFailure { e -> _state.update { it.copy(busy = null, error = classify(e)) } }
    }

    private fun classify(e: Throwable): DataError {
        lastErrorMessage = e.message
        return when {
            e is java.io.IOException -> DataError.Offline
            e is ApiException && e.status == 413 -> DataError.TooLarge
            else -> DataError.Other
        }
    }
```

```kotlin
package dev.logb.android.core.domain

import java.net.URI

sealed interface WebhookCheck {
    data object None : WebhookCheck
    data class Valid(val url: String) : WebhookCheck
    data object Invalid : WebhookCheck
}

/** `api::notifications::validate_webhook`: any http(s) address with a host; blank means none. Private addresses are allowed on purpose. */
object Webhook {
    fun normalize(raw: String): WebhookCheck {
        val url = raw.trim()
        if (url.isEmpty()) return WebhookCheck.None
        val uri = runCatching { URI(url) }.getOrNull() ?: return WebhookCheck.Invalid
        if (uri.scheme?.lowercase() !in setOf("http", "https") || uri.host.isNullOrEmpty()) return WebhookCheck.Invalid
        return WebhookCheck.Valid(url)
    }
}
```
